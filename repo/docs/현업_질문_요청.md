# 현업 확인 요청 문안

> 아래 문안은 현업 직원에게 보낼 수 있도록 정리한 것입니다. **발송은 팀이 직접** 해야 합니다.
> 비공개 정보(실제 사고 내용, 정확한 수치)는 **공개 가능한 범위**에서만 답해 달라고 부탁합니다.

## 보내는 말 (복사용)
안녕하세요. 포스코 K-뉴딜 아카데미 해커톤에서 **연주기 세그먼트 냉각수 누수 예측·예방**을 주제로 준비하고 있습니다.
실제 현장과 맞는지 확인하고 싶어서, 아래 내용을 여쭙습니다. 공개하기 어려운 부분은 "대략 이 정도" 수준으로만 알려 주셔도 충분합니다. 답변 내용은 합성 데이터 가정을 맞추는 데만 쓰고, 기획서와 발표에는 허락하신 범위만 사용하겠습니다.

## 질문 (시간이 되실 때)
1. "월 1회 정도"라고 들은 것은 무엇의 빈도인가요? (누수 경보 / 실제 누수 수리 / 정지)
2. 말씀하신 "세그먼트 냉각수 배관·로터리 조인트"는 **순환하는 기계 냉각수 회로**가 맞나요? (스프레이 냉각수가 아닌지)
3. **로터리 조인트**의 교체 주기와 교체 판단 기준은? **교체 이력(설치·교체 시점)을 익명화해서** 일부라도 받을 수 있을까요?
4. **익명화한 샘플 데이터**(한 구간, 몇 시간 분량이라도)를 받을 수 있을까요?
